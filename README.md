# Prompt Library

A responsive library of copy-ready AI prompts, built with the Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui-style components, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Run `npm run build` to create a production build.

Prompt content and category names live in `lib/prompts.ts`. Search covers titles, descriptions, prompt text, category names, and keywords. The selected category count is shown in the navigation, and each card copies only its prompt text.
